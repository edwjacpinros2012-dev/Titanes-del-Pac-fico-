# Referencias visuales de TITANES DEL PACÍFICO

Coloca aquí copias optimizadas de las referencias aprobadas para el equipo.

## Organización
- `jaegers/`: hojas de diseño y vistas ortográficas de Gipsy, Striker y Cherno.
- `kaiju/`: hojas de diseño por familia y categoría.
- `environments/`: hangar, ciudad costera, base oceánica y evacuación.
- `ui/`: HUD y mapa estratégico.
- `materials/`: muestras de materiales PBR y paletas.
- `vfx/`: referencias de lluvia, niebla, vapor, chispas y reactores.

## Reglas
1. Usa nombres descriptivos en minúsculas, por ejemplo `jaeger-gipsy-front.png`.
2. Mantén las imágenes de referencia fuera de `models/`; una ilustración no es un modelo 3D.
3. Para el juego, convierte los recursos aprobados a GLB/GLTF, texturas PBR o sprites optimizados según corresponda.
4. Registra la página del PDF de origen y el estado: `reference`, `approved`, `in-production` o `integrated`.
5. No subir archivos enormes sin optimizarlos ni incluir material con derechos que no se puedan usar.

La biblia completa está en `docs/VISUAL_REFERENCE_BIBLE.md`.
