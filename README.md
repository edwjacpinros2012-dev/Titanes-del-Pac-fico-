# Titanes del Pacífico

Juego 3D de supervivencia, exploración, recolección, construcción y evolución, desarrollado con **Godot 4** y GDScript.

## Abrir el proyecto
1. Instala Godot 4.
2. Descarga o clona este repositorio.
3. En Godot, pulsa **Importar** y selecciona `project.godot`.
4. Ejecuta el proyecto con F6/F5.

## Prototipo jugable incluido
- Terreno 3D explorable y cámara en tercera persona.
- Movimiento con WASD o flechas.
- Recolección de metal, energía y cristales.
- Mejora de la base con recursos (B).
- Evolución progresiva del titán (T).
- Indicador de recursos y niveles.

## Controles
- **WASD / flechas:** moverse.
- **E:** intentar recoger un recurso cercano.
- **B:** mejorar la base.
- **T:** evolucionar el titán.

## Próximas fases
1. Modelos 3D originales de titanes y animaciones.
2. Biomas, criaturas, amenazas y misiones.
3. Construcción modular de edificios.
4. Árbol tecnológico y evolución por etapas.
5. Guardado de partida, audio y exportación web.

La carpeta `web/` contiene la página de publicación. La versión jugable de navegador requiere exportar el proyecto desde Godot usando la plantilla Web (HTML5/WebAssembly).
