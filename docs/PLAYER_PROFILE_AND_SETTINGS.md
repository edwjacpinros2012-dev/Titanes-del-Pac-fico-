# Player profile and settings

The account-independent local profile is created on first run. The player can rename the pilot locally. Offline play does not require an account or network.

Settings are saved independently from progression:
- Audio levels: master/music/effects.
- Language selection key (translations still need content).
- Subtitles.
- Camera sensitivity.
- Touch-control preference.
- Reduced-motion option.
- Analytics consent (off by default).

No analytics are transmitted by this branch. Settings UI and application to the audio bus/camera/input controllers remain integration work.
